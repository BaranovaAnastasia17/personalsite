Избранные научные и технические источники

1. ECMA-376: Office Open XML File Formats

Ecma International. Стандарт, определяющий структуру файлов Office Open XML. Используется для понимания форматов DOCX и XLSX.

Первоисточник: https://ecma-international.org/publications-and-standards/standards/ecma-376/

2. Open XML SDK

Microsoft. Документация по программному доступу к частям и элементам Office Open XML в среде .NET.

Первоисточник: https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk

3. Structure of a WordprocessingML document

Microsoft. Описание состава и структуры текстовых документов WordprocessingML.

Первоисточник: https://learn.microsoft.com/en-us/office/open-xml/word/structure-of-a-wordprocessingml-document

4. Structure of a SpreadsheetML document

Microsoft. Описание внутренней структуры файлов электронных таблиц SpreadsheetML.

Первоисточник: https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/structure-of-a-spreadsheetml-document

5. How to validate a word processing document

Microsoft. Практический материал по использованию инструментов проверки корректности документа.

Первоисточник: https://learn.microsoft.com/en-us/office/open-xml/word/how-to-validate-a-word-processing-document

6. ISO/IEC 19757-3: Rule-based validation using Schematron

ISO/IEC. Стандарт правил проверки XML-данных, применимых для выражения содержательных ограничений.

Первоисточник: https://www.iso.org/standard/85625.html

7. What We Know About Spreadsheet Errors

Raymond R. Panko. Исследование природы и распространённости ошибок в электронных таблицах.

Первоисточник: https://doi.org/10.4018/joeuc.1998040102

8. Detecting and Visualizing Inter-Worksheet Smells in Spreadsheets

Felienne Hermans, Martin Pinzger, Arie van Deursen. Материал об обнаружении признаков потенциальных проблем между листами таблиц.

Первоисточник: https://doi.org/10.1109/ICSE.2012.6227171

9. Beyond Accuracy: What Data Quality Means to Data Consumers

Richard Y. Wang, Diane M. Strong. Работа, раскрывающая многомерное понимание качества данных с точки зрения потребителей.

Первоисточник: https://doi.org/10.1080/07421222.1996.11518099

10. An Overview of Data Quality Frameworks

Christian Cichy, Stefan Rass. Обзор моделей и подходов к оценке качества данных.

Первоисточник: https://doi.org/10.1109/ACCESS.2019.2899751

11. python-docx documentation

python-docx contributors. Документация по чтению и изменению файлов DOCX средствами Python.

Первоисточник: https://python-docx.readthedocs.io/en/latest/

12. openpyxl documentation

openpyxl contributors. Документация по обработке электронных таблиц XLSX на Python.

Первоисточник: https://openpyxl.readthedocs.io/en/stable/
